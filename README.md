# Caption Bot

Advanced Telegram Auto Caption Bot.

## Planned Features

- Multi-channel support with per-channel settings
- Custom captions and dynamic variables
- Smart episode/season/quality/audio parsing with safe fallbacks
- Colored inline buttons
- Text replacement, filters, forwarding, prefix/suffix, stickers, media details
- Public/private mode
- Force subscribe with public channel link only
- Broadcast and statistics
- MongoDB primary database with optional SQLite backend
- Docker support
- Owner/admin-only management
- Error reporting to owner/admin DM

## Configuration

Copy `example_config.py` to `config.py` and fill in your own credentials.

Never commit real bot tokens, API hashes, or database credentials.
