# Contributing

Please keep changes focused and review the full affected flow before opening a pull request.

## Before submitting

- Run `python -m compileall -q .`
- Run `pytest -q`
- Run `ruff check .`
- Keep secrets out of the repository.
- Keep user-facing text in the appropriate plugin/module.
- Add regression coverage for bug fixes.
